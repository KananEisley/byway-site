# byway-site

Public files for Byway, served by GitHub Pages at https://bywaybrowser.com
(`CNAME`; the old kananeisley.github.io/byway-site addresses forward there):

- `index.html`, `style.css`, `images/`: the website (what Byway is). No scripts.
- `registry.json`: the signed registry of site names. Published automatically by the
  registry server; don't edit by hand (browsers verify its signatures and refuse
  changes).
- `updates/`: signed browser updates (later).
- `lens/`: Byway Lens's page, and its privacy policy and help pages (linked from the App Store).
